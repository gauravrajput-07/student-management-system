# Student Management System

A full-stack web application for managing student records and attendance.

## Key Features

* Student CRUD Operations
* Search Student Records
* Attendance Management
* REST API Integration
* MongoDB Atlas Database

## Tech Stack

* HTML, CSS, JavaScript
* Node.js, Express.js
* MongoDB Atlas, Mongoose
* Postman, Git, GitHub
* Render Deployment
